# Photos of societies

Pictures here come with the app, so they cost nothing to store and show offline. To use one, put the file here (a JPEG or PNG about 1200 pixels wide and under 300 KB), then type its file name, e.g. `hiking.jpg`, in the society's `photo` field in the Firebase console. Students see it once the new version is out.

Only use a photo or logo the society has said you can use.
