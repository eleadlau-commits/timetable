# Photos of places

Pictures here come with the app, so they cost nothing to store and show offline. To use one, put the file here (a JPEG about 1200 pixels wide and under 300 KB is plenty), then type its file name, e.g. `flat-white.jpg`, in the place's `photo` field in the Firebase console. Students see it once the new version is out.

Only use photos the place has said you can use, or that you took yourself.
