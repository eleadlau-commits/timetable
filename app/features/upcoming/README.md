# Upcoming

Everything in the next four weeks, grouped by day.

- **Adds:** **Upcoming** inside the Planner tab, as the list button next to the level switch, or a tab of its own without the Planner. Its view id is `agenda`, kept from version 1 so the app remembers it.
- **Requires:** sessions. **Uses if present:** planner.
- **Saves:** nothing.
