# The photo on Home

The photo of Durham behind the pages at the top of Home goes in **this folder**, named exactly:

```
durham.jpg
```

That's all. The app finds it by that name. Until the file is here, the top of Home simply has no photo.

## Choosing a photo

- **Landscape (wider than tall)**, about **1200–1600 pixels wide**.
- **Under about 400 KB**, so the app stays quick to download. (It's included in the app and the web version.)
- **A JPEG** (`.jpg`). If yours is a `.png` or `.heic`, save or export it as JPEG first.
- **Put the interesting part in the lower right.** The photo is clearest at the bottom right and fades out towards the top left, where the menu, the date and the clock are.
- It's shown **half see-through over the dark top**, so a fairly bright photo works best.
- **Use your own photo, or one you're allowed to use.** The web version is public.

## Changing it later

Replace `durham.jpg` with the new photo, using the same name. Then put it on GitHub as usual. With the next release, everyone gets the new photo.

## Getting it onto GitHub

- **GitHub Desktop:** copy the photo into this folder on your computer (`app/features/home/photos/`), named `durham.jpg`. GitHub Desktop shows it as a new file. Write a short summary (such as "Add the Durham photo") and press **Commit**, then **Push origin**.
- **GitHub website:** open `app/features/home/photos/` in the repository, choose **Add file → Upload files**, drop the photo in (named `durham.jpg`), and press **Commit changes**.
